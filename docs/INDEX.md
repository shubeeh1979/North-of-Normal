Clone Repository\n```bash\ngit clone https://github.com/shubeeh1979/North-of-Normal.git\ncd North-of-Normal\n```\n\n### 2. Run Setup Script\n```bash\nnode setup.js\n```\n\nThe script will:\n- ✅ Check Node.js version\n- ✅ Install dependencies\n- ✅ Create `.env` from `.env.example`\n- ✅ Initialize git repository\n\n### 3. Configure Environment\n\nEdit `.env` with your Base44 credentials:\n```bash\nVITE_BASE44_API_URL=https://api.base44.com\nVITE_BASE44_PROJECT_ID=your_project_id\nVITE_BASE44_API_KEY=your_api_key\n```\n\n### 4. Start Development\n```bash\nnpm run dev\n```\n\nOpen [http://localhost:5173](http://localhost:5173) in your browser.\n\n---\n\n## 📋 Development Checklist\n\n### Initial Setup\n- [ ] Clone repository\n- [ ] Run `node setup.js`\n- [ ] Add Base44 credentials to `.env`\n- [ ] Start dev server with `npm run dev`\n- [ ] Verify app runs on localhost:5173\n\n### Development Workflow\n- [ ] Create feature branch: `git checkout -b feature/my-feature`\n- [ ] Make changes to code\n- [ ] Run linter: `npm run lint`\n- [ ] Run type check: `npm run typecheck`\n- [ ] Test locally: `npm run dev`\n- [ ] Commit changes: `git commit -m \"feat: Add my feature\"`\n- [ ] Push to GitHub: `git push origin feature/my-feature`\n- [ ] Create Pull Request\n\n### Before Deployment\n- [ ] All tests pass\n- [ ] No linting errors: `npm run lint`\n- [ ] No TypeScript errors: `npm run typecheck`\n- [ ] Production build works: `npm run build`\n- [ ] Tested on staging environment\n\n---\n\n## 🌐 Netlify Deployment\n\n### Prerequisites\n- GitHub account with this repository\n- Netlify account (free at [netlify.com](https://netlify.com))\n- Base44 API credentials\n\n### Setup Steps\n\n#### Step 1: Connect GitHub to Netlify\n1. Go to [netlify.com](https://netlify.com)\n2. Click \"Add new site\" → \"Import an existing project\"\n3. Connect GitHub and authorize\n4. Select **North-of-Normal** repository\n5. Review build settings (should be auto-detected)\n6. Click \"Deploy site\"\n\n#### Step 2: Configure Secrets\n\n**In Netlify:**\n1. Site settings → Build & deploy → Environment\n2. Add 3 variables:\n   - `VITE_BASE44_API_URL`: `https://api.base44.com`\n   - `VITE_BASE44_PROJECT_ID`: your_project_id\n   - `VITE_BASE44_API_KEY`: your_api_key\n\n**In GitHub:**\n1. Repository settings → Secrets → Actions\n2. Add 5 secrets:\n   - `NETLIFY_AUTH_TOKEN` - From Netlify user settings\n   - `NETLIFY_SITE_ID` - From Netlify site settings\n   - `VITE_BASE44_API_URL`\n   - `VITE_BASE44_PROJECT_ID`\n   - `VITE_BASE44_API_KEY`\n\nSee [GITHUB_SECRETS.md](./GITHUB_SECRETS.md) for detailed instructions.\n\n#### Step 3: Deploy\n\nAutomated deployment:\n- Push to `main` branch → Automatic production deployment\n- Create pull request → Preview deployment\n- GitHub Actions workflow handles everything\n\n#### Step 4: Verify\n\n- ✅ Netlify build succeeds\n- ✅ Application loads on Netlify URL\n- ✅ All features work (Artists, Songs, Podcasts, Licensing)\n- ✅ API calls succeed\n- ✅ No errors in browser console\n\n---\n\n## 📁 Project Structure Overview\n\n```\nNorth-of-Normal/\n├── src/\n│   ├── components/       #
