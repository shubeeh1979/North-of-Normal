# Getting Started with Melody & Mic\n\n## Prerequisites\n\n- Node.js 16+ (recommend 18 or 20)\n- npm 8+ or yarn 3+\n- Git\n- Base44 account and project\n\n## Quick Start\n\n### 1. Clone the Repository\n\n```bash\ngit clone https://github.com/shubeeh1979/North-of-Normal.git\ncd North-of-Normal\n```\n\n### 2. Install Dependencies\n\n```bash\nnpm install\n```\n\n### 3. Set Up Environment Variables\n\nCreate `.env` file from template:\n\n```bash\ncp .env.example .env\n```\n\nEdit `.env` with your Base44 credentials:\n\n```env\nVITE_BASE44_API_URL=https://api.base44.com\nVITE_BASE44_PROJECT_ID=your_project_id\nVITE_BASE44_API_KEY=your_api_key\nVITE_ENVIRONMENT=development\n```\n\n### 4. Start Development Server\n\n```bash\nnpm run dev\n```\n\nOpen [http://localhost:5173](http://localhost:5173) in your browser.\n\n## Available Commands\n\n### Development\n```bash\n# Start dev server with hot reload\nnpm run dev\n\n# Preview production build locally\nnpm run preview\n```\n\n### Building\n```bash\n# Build for production\nnpm run build\n\n# This creates optimized bundle in dist/ folder\n```\n\n### Code Quality\n```bash\n# Run ESLint\nnpm run lint\n\n# Run TypeScript type checking\nnpm run typecheck\n```\n\n## Project Structure\n\n```\nNorth-of-Normal/\n├── src/\n│   ├── from '@/components/ui/button'\n\nexport function ArtistCard({ artist }) {\n  return (\n    <div className=\"rounded-lg border p-4\">\n      <h3 className=\"text-lg font-semibold\">{artist.name}</h3>\n      <p className=\"text-sm text-gray-600\">{artist.genre}</p>\n      <Button className=\"mt-4\">View Profile</Button>\n    </div>\n  )\n}\n```\n\n### Using Custom Hooks\n\n```jsx\n// src/hooks/useArtists.js\nimport { useQuery } from '@tanstack/react-query'\nimport { getArtists } from '@/api/artists'\n\nexport function useArtists() {\n  return useQuery({\n    queryKey: ['artists'],\n    queryFn: getArtists,\n  })\n}\n```\n\n### Creating API Calls\n\n```jsx\n// src/api/artists.js\nimport { base44Client } from '@/api/client'\n\nexport async function getArtists() {\n  const response = await base44Client.from('Artist').select('*')\n  return response.data\n}\n\nexport async function getArtistById(id) {\n  const response = await base44Client\n    .from('Artist')\n    .select('*')\n    .eq('id', id)\n    .single()\n  return response.data\n}\n```\n\n## Working with Forms\n\n```jsx\nimport { useForm } from 'react-hook-form'\nimport { zodResolver } from '@hookform/resolvers/zod'\nimport { z } from 'zod'\n\nconst schema = z.object({\n  name: z.string().min(1, 'Name is required'),\n  email: z.string().email('Invalid email'),\n})\n\nexport function ContactForm() {\n  const { register, handleSubmit, formState: { errors } } = useForm({\n    resolver: zodResolver(schema),\n  })\n\n  const onSubmit = (data) => console.log(data)\n\n  return (\n    <form onSubmit={handleSubmit(onSubmit)}>\n      <input {...register('name')} />\n      {errors.name && <span>{errors.name.message}</span>}\n      <button type=\"submit\">Submit</button>\n    </form>\n  )\n}\n```\n\n## Database Queries with React Query\n\n```jsx\nimport { useQuery, useMutation } from '@tanstack/react-query'\n\n// Fetching data\nconst { data, isLoading, error } = useQuery({\n
